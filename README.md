## About the Course

CPE 010 covers how to organize and process data efficiently in C++. It starts with the language fundamentals and memory handling, moves through the classic data structures, and ends with analyzing and choosing algorithms for a given problem.

## Running the Code

Each activity folder holds its own source files. Compile with g++ and run:

```bash
g++ -std=c++17 -Wall main.cpp -o main
./main
```

On Windows, run `main.exe` instead of `./main`.

* C++17 with g++ (MinGW or GCC)
